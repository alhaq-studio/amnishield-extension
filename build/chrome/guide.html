🚀 Quick Start Guide

Welcome! Let's get you set up in under 2 minutes.

Step 1: Access the Extension

  • Click the Amn Shield icon in your browser toolbar
  • The popup shows your current protection status
  • You'll see three toggles: Blocking, Content Blur, and DeenTab

Step 2: Enable Protection

  • Toggle Content Blur ON to blur inappropriate images/videos
  • Toggle DeenTab ON if you want Islamic content on new tabs
  • Click ⚙️ Settings to configure blocking options

Step 3: Configure (Optional)

  • In Settings, enable Block Impermissible Content
  • Enable Block Social Media if needed
  • Add custom keywords to block specific distractions
  • Set a password to lock your settings

🔍 Content Blur Guide

The Content Blur feature adds a visual layer of protection by blurring potentially inappropriate images, videos, and other media on web pages.

Quick Toggle

  • Click the extension icon
  • Toggle 🔍 Content Blur ON or OFF
  • Changes apply immediately to all tabs

What Gets Blurred?

🖼️
Images
All <img> tags on web pages
🎬
Videos
All <video> elements
📺
iFrames
Embedded content
🎨
Backgrounds
CSS background images

Keyboard Shortcuts

Shortcut Action Description
Alt + L Toggle Blur Turn blur ON/OFF for current page
Alt + K Toggle Element Blur/unblur element under cursor
💡 Pro Tip: Press Alt+K while hovering over a blurred image to selectively unblur it for viewing.

Advanced Configuration

For full control, go to Settings → Content Blur Settings:

  • Blur Intensity: Adjust slider from 1-50px (default: 20px)
  • Grayscale: Add black & white effect to blurred content
  • Whitelist Domains: Exclude trusted sites from blurring
  • Selective Blur: Choose what to blur (images, videos, etc.)

🚫 Content Blocking Guide

Amn Shield blocks access to inappropriate websites and distracting platforms to help you maintain focus and protect your values.

Blocking Categories

1. Impermissible Content (Haram)

  • Adult/inappropriate websites
  • Gambling sites
  • Alcohol-related content
  • Content against Islamic values

2. Social Media

  • Facebook, Instagram, Twitter/X
  • TikTok, YouTube, Reddit
  • Snapchat, Pinterest, LinkedIn
  • Discord, Telegram, and more

3. Custom Blocklist

  • Add your own keywords (e.g., "gaming", "news")
  • Add specific domains (e.g., "example.com")
  • Export/import blocklists

How to Enable Blocking

  • Click ⚙️ Settings in the popup
  • Toggle Block Impermissible Content ON
  • Toggle Block Social Media ON (optional)
  • Click 💾 Save Changes
⚠️ Important: The browser may ask for permissions when you first enable blocking. Click "Allow" to activate protection.

Custom Blocklist

Add personal distractions:

  1. Go to Settings → Custom Blocklist
  2. Type a keyword or domain
  3. Click Add
  4. Save your changes

Safe Search Enforcement

Amn Shield automatically enforces safe search on:

  • Google
  • Bing
  • DuckDuckGo
  • Yahoo
  • YouTube (Restricted Mode)

🔒 Password & Security Guide

Protect your settings from being changed by setting a password and security question.

Setting Up Security

  • Open Settings
  • Scroll to Password Protection
  • Enter a strong password
  • Click Set
  • Click 📝 Set Security Question
  • Choose a question and enter your answer
  • Click Save
🔐 Security: Your password is stored as a salted hash - never in plain text. Even we cannot see your password!

Password Recovery

If you forget your password:

  1. Click Forgot password? in the locked view
  2. Answer your security question
  3. Set a new password

Emergency Reset

If you forget both password and security answer:

  1. Click Emergency Reset in the recovery screen
  2. This removes password protection
  3. Your blocking settings remain intact
⚠️ Note: Emergency reset is your last resort. Always set a memorable security question!

Password Tips

  • Use at least 8 characters
  • Mix letters, numbers, and symbols
  • Don't use easily guessable passwords
  • Choose a security question you'll remember

⌨️ Keyboard Shortcuts

Quick access to important features without opening menus.

All Shortcuts

Shortcut Feature Description
Alt + L Toggle Blur Turn content blur ON/OFF for current page
Alt + K Toggle Element Blur Blur or unblur the element under your cursor
💡 Tip: Shortcuts won't work when the popup is open. Close the popup first, then use shortcuts on the web page.

Using Element Toggle (Alt+K)

  • Make sure Content Blur is enabled
  • Browse to a page with blurred content
  • Hover your mouse over a blurred image/video
  • Press Alt + K
  • The element will unblur (or reblur if already unblurred)

Platform Differences

  • Windows/Linux: Alt + Letter
  • Mac: Option + Letter
  • Shortcuts work in Chrome, Firefox, and Edge

🔧 Troubleshooting Guide

Content Not Being Blocked

Possible Solutions:

  • Make sure blocking is enabled in Settings
  • Check that you granted permissions when prompted
  • Refresh the page after enabling blocking (Ctrl+R or Cmd+R)
  • Clear browser cache and try again
  • Make sure you're on an http:// or https:// page

Content Blur Not Working

Possible Solutions:

  • Toggle Content Blur OFF then ON again
  • Check if the current site is in your blur whitelist
  • Increase blur intensity in settings
  • Try refreshing the page
  • Some images load dynamically - wait a moment and refresh

Keyboard Shortcuts Not Working

Possible Solutions:

  • Close the extension popup first
  • Make sure you're on a regular web page (not chrome:// or about: pages)
  • Check if another extension is using the same shortcut
  • Try restarting your browser

DeenTab Not Appearing

Possible Solutions:

  • Make sure DeenTab is enabled in the popup
  • Close all existing new tabs and open a fresh one
  • Check if another extension is overriding the new tab
  • Try restarting your browser

Settings Not Saving

Possible Solutions:

  • Click the 💾 Save Changes button
  • Check if browser sync is working
  • Disable other extensions that might conflict
  • Clear browser cache and try again

Password Issues

Forgot Password:

  • Click "Forgot password?" in the locked view
  • Answer your security question
  • Set a new password

Forgot Security Answer:

  • Use Emergency Reset
  • This removes password protection only
  • Your other settings remain intact

Performance Issues

If the extension slows down your browser:

  • Reduce blur intensity to 10-15px
  • Disable blur for background images
  • Reduce the size of your custom blocklist
  • Clear browser cache regularly
Still Having Issues? Contact support with details about your browser version, extension version, and the problem you're experiencing.
