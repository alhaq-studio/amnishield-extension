Amn Shield — Help & FAQ

Guide to setup, recovery, and tips for effective use

Getting Started

  • Use the popup to toggle Block Impermissible Content and Block Social Media.
  • Add custom distractions under Custom Blocklist (e.g., keywords or domains).
  • Set a Password, then choose a Security Question for recovery.
Note: The extension blocks via redirect to a built-in block page for top-level sites and cancels sub-frames.

Password & Security

  • When you set a password, it’s securely stored as a salted hash (not plaintext).
  • Locking requires both a password and a security question to be set.
  • Use the eye icon to show/hide your password while typing. A simple strength hint is shown.

Recovery Options

Forgot Password

  • Click Forgot password? in the locked view.
  • Answer your security question correctly to set a new password.

Emergency Reset

  • If you cannot recover, use Emergency Reset in the recovery screen.
  • This removes password and security data only; your blocking settings remain.

Blocking Rules

  • Top-level pages are redirected to the block page if matched.
  • Embedded frames are blocked to prevent circumvention.
  • Custom keywords extend the block list; edits apply after you save changes.

Troubleshooting

  • If a site isn’t blocked, try refreshing the page after saving settings.
  • Ensure you’re on http or https pages (extension avoids special URLs).
  • Disable conflicting extensions that may override network rules.
