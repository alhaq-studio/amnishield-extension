## Information We Collect

### Data Stored Locally
- **Settings and Preferences**: Your blocking preferences (harmful content, social media, custom keywords, focus schedules)
- **Password**: Encrypted/hashed locally for the extension lock feature
- **Custom Keywords**: User-defined blocking patterns and rules

### Data We DO NOT Collect
- ❌ Personal identification information (names, emails, accounts)
- ❌ Browsing history
- ❌ Website content or URLs visited
- ❌ User analytics or telemetry tracking data
- ❌ Any data transmitted to external servers

## How We Use Information

### Local Storage Only
All data is stored locally on your device using the browser's secure `storage.local` API. Al-Haq Studio does not transmit any data to external servers.

### Data Usage
- Settings are used to configure content blocking rules in real time.
- Password is used for local settings access authentication only.
- Custom keywords and schedules enhance personal filtering preferences.

## Data Security

### Encryption & Security
- All sensitive data is saved using browser-standard secure storage APIs.
- Passwords are hashed locally and never stored in plain text.
- No data transmission occurs outside your browser.

### Access Control
- Only you have access to your extension data.
- Stored data cannot be accessed by other websites or extensions.
- Password protection prevents unauthorized access or disabling of settings.

## Data Sharing

**Al-Haq Studio does not share, sell, or transmit any user data to third parties.** All processing occurs locally on your device. This commitment aligns with our Islamic values of trust (Amanah) and privacy protection.

## Browser Permissions

### Required Permissions
- **storage**: To save your preferences locally.
- **declarativeNetRequest**: To block inappropriate content at the network level.
- **webNavigation**: To monitor active tabs for domain and keyword evaluation.
- **alarms**: To wake up periodically to handle scheduled block timers.
- **Host permissions (`<all_urls>`)**: To apply blocking rules across websites you visit.

### Why These Permissions Are Needed
These permissions are essential for the extension's core functionality and are used only for content blocking purposes, as per Islamic principles of necessity (Darura).
